# 第三周 A 侧设计与验收

## 范围与目标

本次交付对应候选到 Goal、协作路由、变量和数据反馈三项。补齐前两周候选入口缺口；沿用原模型协议和唯一设备执行边界。B 提供真实候选、UTG、执行回调与 Oracle 求值，本次不重写这些模块。

## 输入和状态约束

- Planner 接收带 run、页面、功能和观察来源的候选；模型只能选择候选 ID 和执行步骤，程序冻结来源与公开目标。空候选、跨 run、重复 ID、非法步骤或超时均失败关闭，已发请求仍扣预算。
- 输入步骤沿用 click/text/text_ref，新增 generate:widget=variable 表示需要 Data 提出新文本。候选入口当前仅规划该候选已观察控件上的局部操作，不生成尚未观察页面上的控件；固定 Goal 的后续步骤仍在每轮快照中校验。任意跨页面自动规划不属于本次能力。
- 新变量先是 VariableProposal，绑定 action_id 和页面版本，不能被 value_ref 使用；只有 B 的有规则及证据引用、匹配 run/goal/action/当前页面版本的 PASS 评估才能确认。
- 失败变量不可确认；缺失引用不能用新值替代。旧版 with_variable 作为人工审核变量注入保留，不用于模型直接写入。
- Oracle 求值在 B 侧；A 校验关联并推进相邻步骤，不凭空判 PASS，不将证据引用存在视为内容验证。
- StepAssessment 是 B 完成当前步骤全部必需规则后给出的聚合结果；rule_id 表示该聚合检查标识，oracle_revision 表示冻结规则版本。A 不从单条模型判断推断所有规则通过。最终步骤通过后暂进入 UNKNOWN，完整 Goal 的最终成功与独立评价仍由 B 后续实现。
- GoalSelectionOutcome.create_state 沿用选择后的预算并保存候选来源，不重置模型调用数。当前步骤协议使用字符串索引，因此拒绝重复步骤及重复变量声明。

## 协作流程

新增 collaborate_once 作为可注入入口，沿用四类 DecisionResult。先检查 run、页面版本、终态和 pending，再按反馈路由：PATH_FAILURE/CONSTRAINT_CONFLICT 给 Planner；DATA_FAILURE 给 Data；ORACLE_UNCERTAIN 给 Oracle 并将只读证据需求交 Planner；ENV_FAILURE/AGENT_FAILURE 终止。执行不明优先观察，禁止再发写动作。

反馈带 run_id、goal_id、feedback_id、state_version、action_id 和证据引用；必须与最近已观察的动作关联，重复反馈不能再次调用或扣预算。路径重规划至多预算次数，输入修正每子目标至多两次，补观察每子目标至多一次。Oracle 请求属于模型请求时同样记账。STOP 在新协作入口更新为显式终态。

模型 Data 仅在 generate 步骤请求模型，提供公开 Goal、当前步骤、确认变量、页面和输入拒绝约束；提案只针对该步骤的控件和变量，不得覆盖已确认变量。路径分支返回最新观察需求与重规划，不自行执行 UTG。

设备返回后先等待步骤评估或定向反馈，不重复发送当前步骤。Data 拒绝值从真实返回动作推导，字段约束按子目标保留；只读补观察通过 refresh_observation 更新页面版本，不解除执行不明动作。Oracle 返回 EvidenceProposal 时记录其用量；同轮 Planner/Data 多次模型调用用量累加，缺失用量标为未知。

## TDD 验收

1. 真实来源格式的模拟候选可以冻结 Goal；伪造候选/状态、无效步骤和预算耗尽不能发动作。
2. Data 新值先暂存，未确认时引用失败；执行后经匹配规则评估确认，后续步骤通过 value_ref 复用。
3. 输入拒绝带约束回到 Data，不能重发同一拒绝值；路径反馈进入 Planner；Oracle 缺证据通过 Planner 输出只读观察需求。
4. 过期/跨 run/跨 goal/重复反馈、未知写入、重复评估、无证据 PASS 均不能错误推进或重复执行。
5. 单元与注入式跨模块流程覆盖上述路径，新模块覆盖至少 80%；旧测试继续通过。

## 交付和边界

交付代码、测试、此设计和 A/B 接口更新。报告在 reports 本地保存。真实 Android、真实模型表现、B 的规则冻结和独立评价不由模拟流程替代；本次完成度按 A 侧三项和联合门禁分别记录。

## 对照开发文档的审查结论

- 第一项：已支持注入式候选选择、来源冻结和局部步骤生成；真实 FunctionList/StateCluster 映射等待 B。已观察页面外的自动规划未交付。
- 第二项：已支持 Planner 路径反馈、Data 输入反馈、Oracle 到 Planner 的只读需求和异常终止；路径算法和规则求值仍属于 B，完整恢复案例属于第四周联合门禁。
- 第三项：已支持模型文本生成、日期/长度约束修正、候选变量暂存、B 聚合评估确认和后续引用。日期仅文本输入，不包含日历组件驱动。
- 联合门禁：尚无真实 Android 跨步骤闭环证据，不报告整周联合验收完成。
